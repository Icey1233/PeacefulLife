# 慢慢日常

一个温暖安静的 HTML 小游戏，和小猫「橘子」一起过一天。

直接用浏览器打开 `index.html` 即可游玩，无需安装依赖或联网。也可以在此目录运行 `python3 -m http.server 5173`，然后访问 http://localhost:5173。

如果要使用注册、登录和云端存档，请使用下面的 Node 服务。离线打开或纯静态服务器只支持访客游玩；不要用普通静态服务器发布包含后端配置、密钥或本地数据的项目根目录。

## 注册、登录与云存档

云存档目标为 Bucket `peaceful-life-data` / `UserData/`。每个账号对应 `UserData/账号名/user.json`，存储资料、加盐 scrypt 密码哈希、游戏状态与版本；登录会话存储在该账号的 `sessions/` 下。只由后端访问 OSS，网页不包含阿里云密钥。

```sh
npm ci
npm run dev
```

打开 `http://127.0.0.1:5174` 可测试完整账号流程。**`dev` 是明确的本地开发模式**，数据在 `.local-data/UserData/`，页面会标注，绝不会冒充云端保存。默认的 `npm start` 不会自动降级成本地账号存储。

需要真实 OSS 时，把 `.env.example` 复制为 `.env`，填写服务端专用 RAM 凭证，再运行 `npm start`。已根据你提供的信息预填北京地域。没有服务器时，按 [函数计算部署说明](deploy/README.md) 上传准备好的代码包到 FC。

账号登录后自动每 15 秒保存，可点击「立即保存」。访客与各账号使用独立本机缓存；退出恢复原访客存档。断网失败会保留本机待同步进度，重新登录时会恢复；两处同时游玩出现版本冲突时，由用户选择保留本机或云端进度。云端加速时间重开后保持暂停。

这一版后端按单进程 / 单实例部署设计。原 FC 测试入口已完成真实注册和存档验证；正式入口需单独验收。测试使用隔离的临时本地存储，运行 `npm test`。免费 Vercel 网址的配置见 [Vercel 部署说明](deploy/VERCEL.md)，新增调用连接尚需云端部署验收。

- **睡个好觉**：恢复精力，每 30 秒收获一份小确幸。
- **读书学习**：增加专注、消耗少量精力，每 45 秒收获一份小确幸。
- **陪橘子玩**：增加心情，每 30 秒收获一份小确幸。点击画面里的橘子，还可以摸摸它。
- **歇一会儿**：暂停当前活动，保留进度，慢慢恢复精力。切换到另一项活动会从新一轮开始。
- **同步北京时间**：使用设备时钟计算 UTC+8 时间，不受设备当前时区影响。设备时钟需要准确。
- **自定义时间**：选择日期和时间，或拖动滑杆查看一天的变化。默认停在所选时刻，可以开启 1、60 或 360 倍速的时间流动。
- 天空、太阳、月亮、星星、山景、小屋光线、台灯和墙上的时钟都会随着小屋时间变化。
- 声音默认关闭，点击右上角开启本地合成的轻柔背景音。

人物状态、活动进度、时间设置和小确幸数量自动保存在当前浏览器中。重新打开时，自定义时刻保持暂停。页面在后台时，活动进度、自定义时间与背景音均暂停；北京时间持续同步设备时钟。浏览器禁用本地存储时仍可游玩，但关闭页面后进度不保留。

使用原生 HTML、CSS、JavaScript 和 SVG 绘制，无第三方资源。支持手机布局、键盘操作和减少动画的系统偏好。
